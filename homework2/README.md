## Setup Instructions To Run It
To run this repo first clone this repo locally.
From there you need an to setup an environment. 

**Change myenv to whatever name you like**
1. python3 -m venv myenv -- system - site - packages
2. source myenv / bin / activate
3. pip install django djangorestframework

From the terminal to run the local server to test locally run the command below.Then open port to access the website.

**Must cd to movie_theater_bookings directory**
1. python3 manage.py runserver 0.0.0.0:3000
